`verify_*.py` are the final editor scripts used for the candidate. Run only in a complete asset-bearing UE 5.5.3 development project with this native module/editor helpers built, no PIE currently active, and work saved. Run each separately via the editor Python console using `exec(compile(open(r"<absolute path to script>", encoding="utf-8").read(), r"<absolute path to script>", "exec"))`. Scripts load the existing polished map, create/stop PIE worlds, use production input with explicit fixtures, write their named report beside the script and request editor exit. Back up reports before rerunning; they overwrite their result file. This public checkout lacks the required Content assets, so cloning it alone cannot run these editor suites.
