# Hackathon handoff checklist

## Suggested project description

Pillow Wars: Dream Resonance is a bedroom-scale party-combat prototype starring tiny pajama ninjas with spring-neck bobbleheads. Players trade soft-pillow swings, build Daze for stronger knockback, wind up an uppercut, throw a gravity-affected spare pillow, and gather feathers to replenish stuffing. Recoverable furniture routes create opportunities to return to the fight; falling beyond the boundary eliminates a player. The server controls combat and match outcomes.

The distinctive design combines pillow handling, resource recovery, readable charged attacks, spring-head reactions, and a Resonance timing mechanic. It does not claim that party brawlers or ragdoll-style characters are unprecedented inventions. The intended benefit is accessible social play; no health, educational, or measured community-impact claim has been validated.

## Tech stack

Unreal Engine 5.5.3; C++; Unreal networking; editor Python; Blender; procedural GLB asset generation; Git/GitHub; AI-assisted implementation and artwork workflows. Disclose AI assistance and reference/third-party assets honestly.

## Required before submitting

- Public repository URL, plus a working Windows release download and exact launch instructions.
- Final project description, team member details, and tech stack on Devpost.
- Confirm age/team eligibility and that submitted work was created within the event's permitted dates. Do not assume this merely because the game now runs.
- Show actual gameplay footage, including a visible charged uppercut, feather refill, and two-player agreement. Label scripted-camera clips and distinguish normal speed from slow motion.
- Do one independent Windows-computer playtest and verify the download/extraction flow. Note any network limitations openly.
